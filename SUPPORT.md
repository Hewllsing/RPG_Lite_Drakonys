# Suporte

Obrigado pelo interesse no Drakonys RPG Lite.

## Antes de pedir ajuda

Verifique:

- se as dependencias foram instaladas com `npm run install:all`;
- se o backend tem um `.env` valido;
- se o banco MySQL/MariaDB foi criado com `backend/database/schema.sql`;
- se o frontend consegue acessar a API;
- se voce esta usando a branch `main` atualizada.

## Onde pedir ajuda

- Use Issues para bugs reproduziveis.
- Use Feature Requests para sugestoes de melhorias.
- Use Discussions para ideias abertas quando estiver habilitado no repositorio.

## Seguranca

Nao publique senhas, tokens, `.env` reais ou dados sensiveis em issues publicas.

Para vulnerabilidades, siga [SECURITY.md](SECURITY.md).
