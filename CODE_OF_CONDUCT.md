# Codigo de Conduta

Este projeto segue uma regra simples: trate as pessoas com respeito.

## Comportamentos esperados

- Seja educado e construtivo.
- Explique divergencias tecnicas com foco no codigo e no projeto.
- Ajude pessoas novas a entenderem o contexto.
- Evite comentarios ofensivos, discriminatorios ou pessoais.

## Comportamentos inaceitaveis

- Ataques pessoais.
- Assedio ou intimidacao.
- Linguagem discriminatoria.
- Publicacao de informacoes privadas sem permissao.

## Aplicacao

Mantenedores podem editar, ocultar ou remover comentarios, issues e pull requests que violem este codigo de conduta.

Casos graves podem resultar em bloqueio de participacao no projeto.
