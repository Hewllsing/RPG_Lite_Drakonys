# Politica de Seguranca

## Versoes suportadas

Enquanto o projeto estiver em desenvolvimento ativo, a branch `main` recebe correcoes de seguranca.

## Reportar vulnerabilidades

Nao abra uma issue publica com dados sensiveis, tokens, senhas ou detalhes exploraveis.

Para reportar uma vulnerabilidade, entre em contato com os mantenedores do projeto pelo GitHub e inclua:

- descricao do problema;
- impacto esperado;
- passos de reproducao;
- sugestao de correcao, se houver.

## Escopo

Temas importantes para este projeto:

- autenticacao;
- sessoes de utilizador;
- validacao de dados enviados ao backend;
- SQL injection;
- exposicao de credenciais em `.env`;
- uploads ou assets externos no futuro.

Nunca envie arquivos `.env`, dumps reais de banco ou credenciais para o repositorio.
